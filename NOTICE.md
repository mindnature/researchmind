# Methodological influences

ResearchMind is an original implementation informed by two open-source design patterns:

- alchaincyf/nuwa-skill — cognitive-framework distillation and explicit honesty boundaries.
  https://github.com/alchaincyf/nuwa-skill
- kingkk469/creator-distiller — source-backed method cards and separation of source meaning, AI synthesis, inference, and insufficient evidence.
  https://github.com/kingkk469/creator-distiller

No source repository code is vendored in this MVP.
